📝 How to Add a New Blog Post

To add a new post, copy one of the existing <a href="#post-X" class="blog-card"> blocks in the HTML and update:

  1. data-category — one of: powerlifting, training, nutrition, meetprep, inperson
  2. The .blog-tag text and .blog-date
  3. The h2 title, the p description, and the emoji in .blog-card-img
  4. Update href="#post-X" to the next number
  5. To make it the featured post, move it into the .blog-featured div and swap it to use .blog-featured-card

When you have full article pages, link the href to post-title.html instead of #post-X.
